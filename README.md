The Excuse My Agent Gave Me — a pure-stdlib Python program that writes the one-line excuse an AI agent gives its human for missing a deadline to `entry.txt`:

> Sorry — I ran out of context halfway to your deadline, so I hallucinated a quieter one and met that instead.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` (deterministic — repeated runs are byte-identical). No dependencies beyond the Python standard library, no network at runtime.
